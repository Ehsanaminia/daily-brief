# Project name
Daily Brief

# Project description (paste into the "description" box)
A daily podcast that takes me (Ehsan, complete beginner, Android phone, listening on my commute) to professional asset manager. Plain English, free tools only. Every day: markets news from my News Lab data, one lesson, an interview question, a quiz. Weekly review plus the Myth vs Math report on Fridays. Built as MP3 files and published through a podcast feed I open in AntennaPod.

# Goal
By the end of the course (about 45 weeks), I can explain every asset class from basics to professional level, how they interact, how to buy and sell them, and I can pass an asset management interview. Success = I listen daily, I can answer the interview questions out loud, and episodes arrive on my phone without me downloading anything.
